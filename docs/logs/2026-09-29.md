## Review the Clock's Calibration Instruction

### Finding and correction

Static control-flow review found that the first extraction note inferred the
wrong replacement for the article's printed $0312. The $0313 coarse counter
starts at $15; increasing it causes the counter at $06 to wrap in fewer INC
iterations, so the clock runs faster. The article instead says lowering the
value makes the clock faster. That direction matches the fine delay at $030E:
lowering the LDX operand shortens the DEX/BNE loop. The transcription now marks
$030E as the likely intended address and keeps the printed $0312 as a source
discrepancy. Reset comments in `AGENTS.md` and `amico2000.js` no longer repeat
$0312 as an instruction to follow. No emulator behavior changed.

### Verification

The conclusion follows from the printed listing's addresses and the two loop
termination conditions. `node --check amico2000.js` and `git diff --check`
passed. The clock program was not executed.
