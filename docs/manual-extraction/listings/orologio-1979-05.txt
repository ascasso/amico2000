PROGRAMMA DI OROLOGIO - AMICO 2000/A
====================================

Source: Sperimentare, May 1979, "Home Computer AMICO 2000", part four
Scan: docs/Sperimentare_1979_05.pdf
Printed pages: 436 (description), 437 (loading and use), 438 (code listing)
PDF pages: 6-8
Status: bytes and instructions visually transcribed from the rendered scan.
This is a source transcription, not a claim that the emulator has run it.

The article stores seconds, minutes, and hours in $F9, $FA, and $FB. It uses
decimal mode so the values are packed decimal digits. The limits at $0003-$0005
are $60, $60, and $24. SCADS is the monitor display routine at $FF0C.

LOADING AND USING THE CLOCK (printed page 437)
----------------------------------------------
1. Enter the program from $0300. Press AD, enter 0300, press DA, enter F8,
   then use the up-arrow key to advance after each byte. The next byte at
   $0301 is A5; continue through $033E = 03.
2. Enter the time limits: AD 0003, DA 60; up-arrow to $0004 and enter 60;
   up-arrow to $0005 and enter 24. These are the article's hex input bytes
   for 60 seconds, 60 minutes, and 24 hours in decimal mode.
3. Choose a starting time a few minutes ahead of the actual time. Press RES,
   then DA and enter seconds (ss) at $0000; use up-arrow to enter minutes (mm)
   at $0001 and hours (hh) at $0002. Use two decimal digits for each field.
4. Set the start PC with AD 0300. Press RUN when the chosen time arrives.
5. To change the time, press RES and repeat the starting-time entry and start.

SOURCE DISCREPANCY
------------------
The operating paragraph says to change the value at $0312 to calibrate the
clock: lower speeds it up, higher slows it down. In the printed listing,
$0312 contains the LDA immediate opcode A9; its value $15 is at $0313.
Changing $0312 would change the instruction. The intended coarse calibration
byte appears to be $0313. The fine-adjustment byte $95 is at $030E. This
correction is inferred from the listing; the printed instruction says $0312.
